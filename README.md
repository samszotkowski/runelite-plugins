# MLM activity timer
This plugin adds a timer that counts up in Motherlode Mine, starting when you obtain the first paydirt from a vein. The text turns yellow when there's not much time left, and turns red when the next paydirt will likely deplete the vein.

There's an option in the settings to play the tick-tock sound effect (like when poison resistance is about to expire) when the vein is about to deplete.
